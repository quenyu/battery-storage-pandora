# Pandora — учёт аккумуляторов

HTTP-сервис на Go и PostgreSQL для учёта АКБ: хранение в ячейках, выдача
сотрудникам, возврат и перемещение. Сохраняет историю операций и показывает,
где находится каждый аккумулятор и у кого он на руках.

## Локальный запуск

Нужен Go 1.25 или новее. Все команды выполняются из корня проекта.

### Windows

В PowerShell:

```powershell
./scripts/run-local.ps1
```

Скрипт установит и запустит локальный PostgreSQL, подготовит базу и запустит сервис.

### Через Docker

С установленными Docker и Make:

```sh
make local
```

Команда запустит PostgreSQL, применит миграции, выдаст права и запустит сервис.

После запуска откройте [Swagger](http://127.0.0.1:18080/swagger/) — там можно
посмотреть методы API и отправить запросы. Контракт: [OpenAPI](swagger/openapi.yaml).

## Операции

| Операция | Назначение |
|---|---|
| STORE | Зарегистрировать АКБ и разместить в ячейке |
| TAKE | Выдать АКБ сотруднику |
| RETURN | Вернуть АКБ от текущего держателя в свободную ячейку |
| MOVE | Переместить хранящуюся АКБ в другую ячейку |

Адрес ячейки записывается как `шкаф.полка.ячейка`, например `1.2.1`.

## Демо-данные

При работающем сервисе выполните в другом терминале (нужен Python 3):

```sh
make seed
```

Будут созданы сотрудники, аккумуляторы и примеры операций.
