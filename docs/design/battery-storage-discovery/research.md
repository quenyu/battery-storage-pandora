# Учёт АКБ Pandora

Учебная задача: хранить АКБ, сотрудников и карты, оформлять выдачу, возврат и перемещение, показывать текущее состояние и историю.

Согласованные правила:

- Адрес — три положительных числа `шкаф.полка.ячейка`, без ведущих нулей.
- На адресе находится не более одной АКБ.
- Вернуть АКБ может только сотрудник, который её взял.
- Сотрудник и его карты — отдельные сущности. Смена карты сохраняет держателя и историю.
- Изменение состояния, операция и результат повторяемого запроса сохраняются атомарно.
- История операций не редактируется.

Сотрудники могут быть тестовыми данными. Авторизация API не требуется. Приложение ТСД, оборудование и offline не реализуются.

Сохраняются открытыми вопросы повторного назначения старой карты другому человеку и регистрации АКБ без размещения. Пока карта не передаётся другому сотруднику, а регистрация включает STORE.
