# Требования

Система хранит сотрудников, карты и АКБ. Маршруты и примеры запросов описаны в `openapi.yaml`, доступны в Swagger.

Действия:

- STORE: создать АКБ и разместить на свободном адресе; первая версия состояния.
- TAKE: выдать размещённую АКБ сотруднику, выбранному по активной карте.
- RETURN: вернуть выданную АКБ на свободный адрес. Сотрудник должен совпадать с держателем.
- MOVE: переместить размещённую АКБ на другой свободный адрес.

Текущее состояние — STORED с адресом или ISSUED с держателем. Каждое действие увеличивает номер состояния на один и создаёт операцию. Номер состояния нужен для порядка истории и проверки конкурирующих изменений; он не является версией API.

Адрес — текст вида `1.2.3`, без ведущих нулей. История сохраняет исходный и конечный адреса. Текущий адрес хранится в АКБ для поиска и проверки занятости.

Карты хранятся отдельно от сотрудников; у сотрудника может быть несколько активных карт. Замена отключает указанную старую карту, не меняя сотрудника. Сотрудника с выданными АКБ отключить нельзя.

Чтение: поиск по коду, статусу, адресу или держателю; история АКБ и сотрудника; общий журнал с фильтрами; выданные сотруднику АКБ. Списки имеют limit и next_cursor.

Изменяющие запросы требуют UUID Idempotency-Key. Повтор ключа с прежним путём и телом возвращает исходный ответ. Другое содержимое с тем же ключом вызывает конфликт. Авторизация и разделение прав не используются.
